# 重新设计:弹簧活塞式变截面流量计(证据驱动)

基于本项目从 ifm SBZ224 原理出发、一路做到**验证级轴对称 CFD**(管流解析验证 0.28%)
的全部结论,对浮子与整机做一次干净的重新设计。核心理念:**把精力放在真正决定计量的
"主节流口(锐利计量边 + 锥孔环隙)"上,去掉被 CFD 证明无效的前脸花样(凹坑/锥面槽)。**

## 1. 设计取舍 ← 证据

| 设计决定 | 依据(本项目实测/验证) |
|---|---|
| **保留并强化锐利计量边**(Ø12 锐边 + 短计量柱段) | 控制性边缘的锐度把分离点钉死 → Cd 对 Re/粘度最不敏感(粘度免疫的真正杠杆) |
| **钝迎流面**(平钝面,非流线圆头) | 轴对称 CFD:blunt 阻力(38→9.8)明显高于 rounded(24→5.9)且更 Re 稳定 → 灵敏度/稳定性更好 |
| **去掉前向凹坑(杯)** | 轴对称 CFD:cup6≈cup2≈blunt,阻力差 <0.1% → 凹坑对计量**无影响**;徒增加工与潜在问题 |
| **去掉前锥环形槽** | A/B CFD:前锥(上游低速区)开槽 ΔP 逐点吻合、β 不变 → 对计量无影响 |
| **不为"脉动"加深空腔** | 轴对称(正确几何)流动**定常**(rms≈0)→ 2D 的 210% 脉动是平面假象,不存在该问题 |
| **锥孔(渐扩)做线性化** | 变截面原理:位置 ∝ 流量;锥度决定量程比 1:50 |
| **弹簧主导(非重力)** | 力平衡 ΔP·A_f = 弹簧力 → 安装方向无关(优于纯重力转子) |
| **中心导杆 + 流线锥尾** | 定心/防转、稳定尾流(减少阻力散布);稳态 CFD 已定常,导向主要是机械稳健性 |
| **前置 200 µm 过滤、316L/FKM** | 沿用原器件:冷却液/乙二醇工况、耐压耐蚀 |

## 2. 浮子(新外形)

- **钝平迎流面**,直径 **Ø12**,终止于 **90° 锐利计量边**(控制性边缘)。
- **短计量柱段 ~3 mm**(Ø12),与锥孔形成可变环隙,改善线性与重复性。
- **流线锥尾**(Ø12 → ~Ø3,长 ~20 mm):稳定尾流、兼作导向与磁铁载体。
- **中心导杆孔 Ø3.2**:套在固定导杆上,定心 + 防转。
- **内置环形磁铁**(密封于体内),供外部非接触位置检测。
- **不设**前向凹坑、不设锥面槽(CFD 验证无益)。
- 总长 ~26 mm;材料 **316L**,磁铁全密封。

## 3. 整机

- **锥孔**(渐扩):零位环隙 ~0.2 mm → 满量程 ~3.2 mm,行程 ~20 mm。
- **阀座(止回)**:零流量时浮子落座密封,防倒流。
- **弹簧**:k ≈ 150 N/m,预紧 ≈ 0.57 N(对应 ΔP 5→31 kPa,覆盖 1–50 l/min)。
- **导杆**:中心固定,两端蜘蛛支撑。
- **位置传感**:磁致伸缩或 AMR 阵列读磁铁轴向位置 → **4–20 mA + IO-Link**;开关/频率可选。
- **接口/防护/认证**:G½ 内螺纹、IP65/67、−10…100 °C、200 bar(沿用 SBZ224 等级)。

## 4. 量程与精度(解析模型)

- 量程 **1–50 l/min**(水),动态 **1:50**;锥孔 + 弹簧按 `Q = Cd·A_a(h)·√(2ΔP(h)/ρ)` 标定。
- 单点 span 标定 + 校准系数;锐边使 Cd 在工作区尽量平 → 低流量/高粘度漂移小。

## 5. 诚实的边界

- 轴对称 CFD 不含周向失稳(m=1,2,3);但它正确抓住主导的径向/环隙物理。若要追周向稳定性,
  需 GPU 全 3D 或实流标定。
- 绝对 Cd 受高阻塞影响偏大(真实变截面计同理);有意义的是相对趋势与边缘锐度的作用。
- 凹坑等空腔在现实中的价值多在**机械层面**(定心/防卡/减重/旋转增稳),非本稳态 CFD 范畴;
  本设计用**导杆 + 流线尾**实现同等机械稳健性,避免空腔的加工与潜在脉动风险。
