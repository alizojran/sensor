# 浮子(弹簧活塞)流量计 — 浮子形状设计 + 精度仿真

针对 ifm **SBZ224**(SB 机电式 / 弹簧活塞变截面流量计)的原理,设计一个浮子并用
Python 仿真不同流量、不同介质下的读数精度。

## 1. 浮子形状的设计要求

| 要求 | 为什么 | 本设计的做法 |
|---|---|---|
| **锐利计量边** | 让流动分离点固定在边缘 → `Cd` 几乎与雷诺数/粘度无关(viscosity-immune) | Ø12 mm 直角(90°)计量肩边 |
| **导向 / 定心** | 防止偏心和摆动(偏心环隙会改变 `Cd`),防卡滞 | 下游 3 条导向筋(或中心导杆) |
| **锥面 + 密封座** | 兼任**止回阀**,零流量时密封 | 上游 60° 锥面落在阀座上 |
| **内置轴对称磁铁** | 位置信号线性、可重复;磁定心 | 中心轴向 NdFeB 磁铁 |
| **受力面足够 / 质量受控** | 信号灵敏、稳定 | Ø12 mm 受压面,弹簧主导 |
| **流线型尾部** | 抑制涡激振动 | 短锥形尾裙 |
| **缝隙不过小 + 前置过滤** | 防颗粒堵塞 | 起始环隙 0.2 mm,建议 200 µm 过滤 |
| **配合锥孔做线性化** | 使 位置∝流量 在 1:50 量程内近似线性 | 锥度 a≈0.15 |

## 2. 设计尺寸(与仿真一致)

- 计量边直径 `Df = 12 mm`,行程 `H = 20 mm`
- 环隙 `0.20 mm → 3.20 mm`(锥度 a=0.15)
- 弹簧:预紧 `F0 ≈ 0.57 N`,刚度 `k ≈ 147 N/m`
- 压降 `≈ 5 → 31 kPa`;水流量跨度 `≈ 1 … 52 l/min`(覆盖 1–50 l/min)

## 3. 仿真结论(单点 span 校准下的读数误差)

`Cd(Re) = Cd∞·(1 − β/√Re)`;锐边浮子 β 小、球形浮子 β 大。

| 介质 | 锐边浮子最大误差 | 球形浮子最大误差 |
|---|---|---|
| 水 20 °C | **0.5 %** | 2.8 % |
| 冷却液/乙二醇(温) | **1.2 %** | 6.6 % |
| 乙二醇(冷启 0 °C) | **2.1 %** | 12.2 % |

- 误差在**低流量(低 Re)最大**,流量升高趋近 0(Re 升高,`Cd` 接近标定值)。
- **粘度越大误差越大** —— 这正是"锐边/viscosity-immune 浮子"对水/乙二醇/冷却液
  混用场合至关重要的原因。

## 4. CFD 流场(LBM)

用格子玻尔兹曼法(D2Q9-BGK,纯 numpy)做了浮子在锥孔中的**子午面 2D** 流场
(Re≈150,层流——正是粘性介质/低流量这一最关键工况):

- **速度场+流线**:流体经可变环隙加速(峰值 ≈ **6.5× 入口速度**),在**锐边分离**,
  尾部形成**回流涡**。
- **涡量场**:剪切层从锐边规则脱落——**分离点被钉死在边缘**,不随 Re/粘度漂移,
  这就是 viscosity-immune 的流体力学根源。
- **压力场**:迎流面高压、环隙/尾部低压;前后**压差 ΔP** 正是顶起浮子的力
  (对应 `ΔP·A_f = 弹簧力`)。

> 说明:平面近似(非轴对称),用于展示流场拓扑与机理,非定量轴对称解。

## 5. A/B 对比:前锥是否开"环形锐边槽"

对同一浮子做了 **光面锥 vs 前锥带环形锐边槽** 的对比(CFD 同条件,Re 扫描反算 Cd)。

**结论(诚实的反直觉结果):在已有锐利主计量边的浮子上,前锥环槽对精度几乎无影响。**

- CFD 实测:两种几何在 Re=45/90/180 三点的 ΔP **逐一吻合**(差异 <0.3%),
  拟合 `Cd=Cd∞(1-β/√Re)` 得 **β: 2.366 vs 2.370**(差 <0.2%,数值噪声内)。
- 流场基本一致;槽内只产生**局部小驻涡**(处于低速区,够不到主节流口)。
- 物理原因:**Cd 由主节流口(锐主边 + 窄环隙)决定,前锥处于上游低速区**,
  在那儿开槽改变不了节流口的分离/损失。

**那槽什么时候才有用?**(本 2D 稳态仿真未覆盖,属已知工程依据)
- 当**主读数边不是锐边**(球形/圆角浮子)时,槽/锐肩是**创造固定分离线**的主手段;
- **机械增稳**:斜/螺旋槽使浮子自转 → 离心定心、防贴壁卡滞。

> 即:决定精度的是**控制性边缘(主节流口)的锐度**;主边已经锐,再在前锥补槽是冗余。

## 6. A/B/C 对比:钝头"前向圆柱凹坑(杯)" vs 钝头 vs 圆头

修正几何后(钝头 Ø12 + **前向圆柱凹坑 Ø8×深2** + 锥尾),用**形阻(对浮子表面压力积分)**
比较三种头型(同最大直径、同锥尾,仅前端不同)。这种钝体浮子靠**阻力**平衡弹簧,
关键指标是阻力系数 `Cd=Cd∞(1+β/√Re)` 的 **β(Re 依赖,越小越粘度免疫)**。

| 头型 | Cd∞(阻力大小) | **β(越小越免疫)** |
|---|---|---|
| **杯(带前向凹坑)** | **12.0(最大)** | **1.69(最平)** |
| 钝(平钝面,无坑) | 9.2 | 4.48 |
| 圆头(圆滑鼻) | 5.6 | 4.98 |

> ⚠ **更正(见 §8 验证)**:其中"凹坑 β=1.69 → 最粘度免疫"这条**后被推翻**——
> 该 β 是在凹坑**强脉动**下时均得到的,不可靠(同一凹坑改头长 β 就从 1.69 跳到 4.60)。
> **可靠的只有"阻力最大"这条。** 粘度免疫一项本 2D 模型测不准,见 §8。

**结论(修正后):**
1. **阻力最大(可靠)**(像风杯/降落伞,Cd 高)→ 单位流量举力大、**灵敏度高**;
2. ~~Cd 随 Re 最平→最粘度免疫~~ —— **未证实**(见 §8,清洁测量下深腔 β 反而更大)。

**诚实的注意点:**
- 前向空腔使流动**非定常**(腔体自激脉动),阻力/流场为**时间平均**;实际可能伴随
  一定脉动/噪声(空腔的固有代价)。
- 绝对 Cd 偏大是**高阻塞**(浮子近乎占满流道,真实变截面计也如此)所致;
  有意义的是 **β 与相对排序**,不是绝对值。
- 2D 子午面、低 Re 层流近似;水的高 Re 端为外推。

## 7. 凹坑尺寸怎么选(深度 & 直径)

**方法基础**:前向空腔流动由**深径比 d/Dp** 主导(浅腔剪切层拍打 vs 深腔稳定驻涡;
Charwat/Rossiter/Gharib-Roshko),阻力量级查 Hoerner《Fluid-Dynamic Drag》(空心杯
Cd≈1.4),脉动频率用 Rossiter 公式校核共振。CFD 参数扫描(Re=150,时间分辨阻力)结果:

| d (Ø8) | d/Dp | Cd | 脉动 RMS% |
|---|---|---|---|
| 1 | 0.12 | 12.9 | 40% |
| 2(原设计) | 0.25 | 13.9 | **211%** |
| 3 | 0.38 | 13.6 | 228% |
| 4 | 0.50 | 13.4 | 127% |
| **6** | **0.75** | 13.0 | **17%** |

- **脉动由 d/Dp 主导且非单调**:最猛在 **d/Dp≈0.25–0.5(>200%)**,深到 **d/Dp≥0.75 骤降到 17%**
  (稳定驻涡);阻力 Cd 几乎不变(~13)。两组扫描(变深/变径)在 d/Dp 上基本重合。
- **直径**:固定深度增大坑径会**降低 d/Dp → 落入拍打区**(Ø10/d3 脉动 310%)。要更大坑径
  (更高阻力)必须**按比例加深**以保持 d/Dp≥0.75。

**选取建议**:
- 直径 **Dp/D_头 ≈ 0.6–0.7**(Ø8 合适),保留锐利坑口、鼻壁 ≥1.5–2mm;
- 深度 **d/Dp ≈ 0.75–1.0 → Ø8 对应 d≈6–8mm**(**不是 2mm**,2mm 恰在最糟的拍打区)。

> 注意:2D 平面会**高估**空腔脉动幅值(真实轴对称环涡更稳),绝对 % 偏大,但 d/Dp 主导
> 规律与转变位置可靠;深腔的粘度免疫(β)建议在 d≈6mm 再复核一次。

## 8. 验证:推荐深腔(Ø8×深6)的 脉动 + 粘度免疫(诚实结果)

对 **Ø8×深2(原,d/Dp=0.25)** vs **Ø8×深6(推荐,d/Dp=0.75)** 做同条件复核
(同 Lh=8;Re 扫描测 β;Re=150 长时程测脉动/频谱)。

| | d=2(浅) | d=6(深) |
|---|---|---|
| 脉动 RMS@Re150 | 211% | **20%** ✅ |
| 频谱 | 强峰 | 平 ✅ |
| Cd∞(阻力) | 10.2 | 8.0 |
| **β(免疫,越小越好)** | 4.60 | **7.93**(更差)|

**两条结论,一好一坏,如实记录:**
- ✅ **脉动**:深腔确实**大幅降脉动**(各 Re 下 2–25% vs 浅腔 42–243%)——**可靠**,
  这就是"如何避免空腔脉动"的答案:**加深到 d/Dp≈0.75**。
- ⚠ **粘度免疫**:**未能证实,反而存疑**。清洁测量(深腔脉动小→时均可靠)下
  深腔 β=7.93 比钝/圆头(4.5/5.0)还大;且同一 Ø8×2 凹坑 β 随头长从 1.69 跳到 4.60。
  → **本 2D 时均 LBM 无法可靠分辨 β**;§6 的"凹坑最免疫"很可能是脉动假象。
- 注:低 Re(高粘度工况)端 深/浅腔阻力相同(Re=50 均为 17.0),故深腔不损低速灵敏度。

**底线**:凹坑可靠的好处是**高阻力(灵敏度)**;深腔(d/Dp≈0.75)再叠加**低脉动**。
**"粘度免疫"需更高保真度(轴对称/3D 或实验)才能定论**,勿据此 2D 结果下结论。

## 9. 轴对称(对回转体即"3D-正确")CFD:推翻 2D 的凹坑结论

全 3D 在纯 numpy/CPU 不现实(单次~1h、测 β 要十几小时、受限几何难验证)。对回转体,
正确且可行的是**轴对称 N–S**。自建交错网格分步投影求解器,**用 Hagen–Poiseuille 解析
抛物线验证(最大误差 0.28%、中心/平均=1.993)**,再对 cup6/cup2/blunt/rounded 扫 Re=50–400
(无散度 1e-15,两种独立阻力算法 CV/表面 交叉一致)。

| 头型 | Cd(Re=50→400) | Re 敏感度 |
|---|---|---|
| cup6 深腔 | 38.0→9.79 | Cd∝Re^−0.65 |
| cup2 浅腔 | 38.0→9.79 | Re^−0.65 |
| blunt 钝 | 38.0→9.79 | Re^−0.65 |
| rounded 圆 | 23.9→5.85 | Re^−0.68 |

**可信结论(推翻之前 2D 的两条):**
1. **流动全定常(rms≈0%)** → 2D 的"210% 脉动 / 必须 d/Dp≥0.75"是**平面几何假象**(平面假设
   造出了不存在的涡脱落);第 7、8 节据此给的尺寸建议不成立。
2. **cup6 ≈ cup2 ≈ blunt,阻力差 <0.1%** → **前向凹坑(深/浅/无)对计量阻力几乎无影响**;
   阻力由**环隙阻塞**主导,不是前脸细节。第 6 节"凹坑提升灵敏度/免疫"也不成立。
3. **rounded 阻力明显更低** → 真正起作用的是"钝 vs 圆"这种**大尺度迎流形状**,不是凹坑。
4. Re 50–400 内各形状 Cd∝Re^−0.65~−0.68、**Re 敏感度相近,均无"粘度免疫平台"**,凹坑不改善。

> **贯穿全部 CFD 的可靠主线**:在这种几乎占满流道的浮子里,**环隙(主节流)决定一切,
> 前脸细节(锥面槽 / 前向凹坑)对计量次要**。这与最早的"前锥开槽无效"一致。
> 轴对称局限:不含周向失稳;但它正确抓住主导的径向/环隙物理,而 2D 的脉动来自错误几何。
> 凹坑在现实中的价值多在**机械层面**(定心 / 防卡滞 / 减重 / 旋转稳定),非本稳态 CFD 所能体现。
